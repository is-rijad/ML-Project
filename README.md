# ML-Project

## Pokretanje projekta
 - Otvoriti terminal i napraviti novi virtual environment komandom `uv venv`
 - Aktivirati isti komandom `.venv\Scripts\activate`
 - Otvoriti `source.ipynb` i izabrati kernel
 - Ukoliko se novokreirani kernel ne prikazuje, refreshovati listu
 - Ukoliko se prilikom pokretanja kernel zablokira prilikom izvršavanja prve komande, restartovati isti
